# The Pleroma Archive

A neutral repository of Gnostic records, published as a static site on GitHub Pages.
It is a companion project to [The Church of Barbelo](https://tribbles69.github.io/Church-of-barbelo-/)
and is kept editorially independent of the Church's teaching.

No build step: every page is a self-contained HTML file.

- `index.html`: home, mission and library directory
- `library.html`, `restored.html`, `library/restored.html`: restored texts (under curation)
- `submissions.html`, `user-submission.html`: community submissions
